# What does the conductor do on its own, and what does it bring to you?

Type: grilling
Status: open
Blocked by:
Map: [Each effort has a conductor](../map.md)

## Question

Draw the line between what the conductor does without asking and what becomes a "needs you" item. Go through each action and decide which side it falls on:

- Start an agent on a frontier ticket an agent can take (AFK).
- Start the conversation for a ticket that's your move (HITL), or only tell you it's waiting.
- Choose the order when several tickets are on the frontier.
- Merge a two-way-door PR; merge a one-way-door PR (today: "Merge #N?" card).
- Add, split or close tickets; graduate fog; rule something out of scope.
- Start the hand-over (`/to-spec`, `/to-tickets`) once Decide is clear.
- Run `/retro` after a run; close the effort once everything has landed.
- Stop or restart a worker that seems stuck.

Also decide: is that line the same for every effort, or set per effort (an autonomy level), and how does the user change it?
